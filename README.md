# 🏰 RogueTower - 2D Tower Defense Game

> 一款基于 Unity 开发的 2D 塔防游戏，采用数据驱动架构与自定义寻路系统。  
> B站演示视频：[点击观看](https://www.bilibili.com/video/BV1cDVz6UEmy/)

## 📖 项目简介

这是一款我个人从零独立开发的 2D 塔防游戏，初衷是深入理解游戏架构、性能优化和设计模式。  
游戏支持多波次敌人、多种防御塔与子弹类型，所有数值和行为均通过 `ScriptableObject` 集中配置，实现了代码与数据的彻底分离。

**开发周期**：2026.4 - 2025.5
**开发工具**：Unity、C#、Visual Studio / Rider

## ✨ 技术亮点

### 🧱 框架与架构
- **数据驱动设计**  
  关卡、敌人波次、防御塔属性、子弹参数、特效音效等所有配置均使用 `ScriptableObject` 管理。  
  策划可以在不接触代码的情况下自由组合塔的攻击模式与数值曲线，极大提升迭代效率。

- **OOP 继承体系**  
  塔与子弹采用「基类 → 种类 → 具体类」三层继承结构。  
  - 基类定义公共逻辑（索敌、攻击间隔、升级）。  
  - 种类层抽象特殊行为（范围伤害、连锁攻击）。  
  - 具体类只负责实现细微差异，配合数据驱动实现“行为继承，数值外置”。

- **单例服务与管理器解耦**  
  核心系统由多个专职 `Manager` 驱动（`GameManager`、`LevelManager`、`ScoreManager`、`AudioManager` 等）。  
  每个单例均采用懒加载与严格的生命周期管理，避免循环依赖。`GameManager` 仅作为协调者，不再承担所有业务逻辑。

### 🗺️ 地图与寻路
- **Tilemap 自定义寻路系统**  
  弃用现成寻路插件，基于 `Tilemap` 栅格结合 **射线检测** 实现动态寻路。  
  支持场景中可破坏障碍物的实时路径重算，确保怪物总能在变化的地形中找到正确路径。

### 🎯 战斗与表现

- **双 Canvas 架构（UI 动静分离）**  
  跟随单位的血条（世界空间 Canvas）与静态 HUD（屏幕空间 Canvas）彻底分离，避免 Canvas 合并重建导致的 DrawCall 激增。  
  静态 UI 使用面板栈管理，支持多窗口互斥与平滑过渡。


### 🔧 性能与优化
- 动静 UI 分离降低 UI 模块重建开销
- 单线程寻路在小规模地图上确保性能与准确度

## 🎮 玩法概述

- 在地图关键位置建造防御塔，阻止一波波敌人抵达终点。
- 每种塔拥有独特的攻击方式：单体高伤、范围减速、连锁闪电等。
- 击败敌人获得金币，升级你的塔，或建造更多塔来应对越来越强的敌人。
- 地形可被部分技能破坏/改变，影响怪物路径（需配合动态寻路）。
